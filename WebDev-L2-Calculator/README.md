# WebDev-L1-Calculator

A responsive browser-based calculator developed for **Task 1** of the **Oasis Infobyte Web Development & Designing Internship**.

## Features

* Basic arithmetic operations (+, −, ×, ÷)
* Decimal support
* Clear and Backspace buttons
* Division-by-zero error handling
* Operator chaining
* Responsive UI using CSS Grid
* Built with Vanilla JavaScript

## Technologies

* HTML5
* CSS3
* JavaScript
