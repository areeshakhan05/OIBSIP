# Authentication System

A simple full-stack authentication system that enables users to register, log in, and access protected content after successful authentication.

## Features

* User registration
* User login authentication
* Protected page access
* Form validation
* Backend server handling using Node.js and Express.js

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js

## Installation & Setup

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project directory:

```bash
cd WebDev-L2-AuthenticationSystem
```

3. Install dependencies:

```bash
npm install
```

4. Start the server:

```bash
node server.js
```

5. Open the application in your browser:

```
http://localhost:3000
```

## How It Works

1. Users create an account through the registration page.
2. Registered users can log in using their credentials.
3. Successful authentication grants access to the protected page.
